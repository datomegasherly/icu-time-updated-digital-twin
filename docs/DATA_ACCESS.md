# Source data access and ethics

Only individually authorized, credentialed researchers can access restricted PhysioNet MIMIC-IV and eICU-CRD data. Do not share the data, raw source files, patient-level derived datasets, trained artifacts that may leak sensitive information, credentials, data-bearing logs, or pre-built project DuckDB.

- MIMIC-IV version **3.1**: https://physionet.org/content/mimiciv/3.1/ ; DOI 10.13026/kpb9-mt58.
- eICU-CRD version **2.0**: https://physionet.org/content/eicu-crd/2.0/ ; DOI 10.13026/C2WM1R.

These are the releases *cited in the manuscript*. The precise locally downloaded versions and acquisition records must be confirmed by the authors before publication. PhysioNet requires individual credentialed access, applicable human-subject protection training and acceptance of the data use agreement. Its license explicitly requires contributing code associated with published findings to a repository accessible to the research community.

PhysioNet reference: https://physionet.org/content/mimiciv/view-license/3.1/ and https://physionet.org/content/eicu-crd/view-dua/2.0/.

Source-database ethics oversight **does not by itself establish institutional ethics review or waiver for this secondary analysis**. The authors are responsible for obtaining or documenting the institution's determination, as appropriate, before submission. Never state that an ethics committee approved or waived this study without evidence.
