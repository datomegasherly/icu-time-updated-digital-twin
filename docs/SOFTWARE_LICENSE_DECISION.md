# Choose a code license before publication

No license is assigned in this candidate because the authors have not explicitly selected one. GitHub repository visibility alone is not a license granting reuse rights. Discuss a code license with both authors and any relevant university policy. MIT, BSD-3-Clause and Apache-2.0 are common permissive choices, but only choose after confirming ownership and author approval. Do **not** apply a license to restricted PhysioNet data; such data are not included here.
